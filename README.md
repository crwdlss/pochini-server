# 🔧 Почини сервер
![CI](https://github.com/crwdlss/pochini-server/actions/workflows/ci.yml/badge.svg)

Тренажёр для DevOps на русском: 10 «сломанных серверов» от простого к сложному.
Каждый сервер — Docker-контейнер, поэтому ломается только он, а твоя система остаётся целой.
Вышел (`exit`) — контейнер удалился. Запустил заново — сервер снова сломан.

## Что нужно

- Linux с Docker (например, Ubuntu Server в UTM).
- Установить Docker на Ubuntu:

```bash
sudo apt update && sudo apt install -y docker.io
sudo usermod -aG docker $USER   # чтобы запускать docker без sudo
# выйди из SSH и зайди снова, чтобы группа применилась
docker run --rm hello-world     # проверка
```

## Как перенести на виртуалку с Mac

```bash
# на Mac (в папке, куда скачался архив):
scp pochini-server.tar.gz <user>@<ip-виртуалки>:~

# на виртуалке:
tar xzf pochini-server.tar.gz
cd pochini-server
```

## Как играть

```bash
./run.sh 01
```

Внутри сервера доступны команды:

| Команда | Что делает |
|---|---|
| `task`  | показать условие |
| `hint`  | подсказки по одной, от лёгкой к почти-ответу |
| `check` | проверить решение |
| `exit`  | выйти (всё сбросится) |

Первый запуск займёт пару минут: Docker скачает Ubuntu и установит утилиты. Дальше задачи запускаются за секунды.

## Задачи

| № | Задача | Сложность | Чему учит |
|---|---|---|---|
| 01 | Nginx не запускается | ⭐ | `nginx -t`, чтение ошибок конфига |
| 02 | 403 Forbidden | ⭐ | права доступа, пользователи, логи nginx |
| 03 | Кончилось место на диске | ⭐⭐ | `df`, `du`, скрытые файлы |
| 04 | Порт занят | ⭐⭐ | `ss`, `lsof`, процессы и порты |
| 05 | Скрипт не запускается | ⭐⭐ | chmod, shebang, CRLF vs LF |
| 06 | Приложение не видит бэкенд | ⭐⭐⭐ | `/etc/hosts`, резолвинг, `getent` vs `dig` |
| 07 | Процессор загружен на 100% | ⭐⭐⭐ | `top`, дерево процессов, «воскрешающиеся» процессы |
| 08 | Cron молча не делает бэкап | ⭐⭐⭐⭐ | окружение cron, PATH, логирование |
| 09 | Диск полный, но файлов нет | ⭐⭐⭐⭐ | удалённые открытые файлы, `/proc/<pid>/fd` |
| 10 | 502 Bad Gateway | ⭐⭐⭐⭐⭐ | цепочка nginx → приложение, переменные окружения |

## Правила, которые реально прокачивают

1. **15–20 минут без подсказок.** Застрял — тогда `hint`, и только одну.
2. **Веди заметки:** что увидел → какая гипотеза → какой командой проверил.
3. **После `check` объясни решение вслух** за 1–2 минуты. Это и есть ответ на собеседовании.
4. Ответы с разбором лежат в `SOLUTIONS.md`. Открывай только после решения.

## Как устроено (тоже часть обучения)

```
base/Dockerfile        общий образ: Ubuntu + nginx, curl, python3, cron, lsof...
base/Dockerfile.task   образ конкретной задачи поверх общего
base/entry.sh          что происходит при входе на сервер
base/bin/              команды task, hint, check
tasks/NN-*/
    TASK.md            условие
    prepare.sh         ломает сервер при сборке образа
    start.sh           ломает сервер при запуске (процессы, сервисы)
    check.sh           автопроверка
    hint.txt           подсказки, по одной на строку
    run.flags          доп. флаги docker run (например, маленький диск)
run.sh                 сборка и запуск задачи
```

Разберись, как работает каждый файл: это готовый пример Docker, bash и автоматизации для портфолио.
