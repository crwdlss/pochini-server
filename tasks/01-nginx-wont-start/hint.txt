Сначала узнай, запущен ли nginx вообще: ps aux | grep nginx
У nginx есть встроенная проверка конфига. Посмотри: nginx -h
nginx -t покажет файл и номер строки с ошибкой. Иногда виновата строка ВЫШЕ указанной.
После исправления конфига nginx нужно запустить: nginx (или nginx -s reload, если уже работает).
