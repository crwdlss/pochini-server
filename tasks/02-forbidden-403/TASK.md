# Задача 02 — 403 Forbidden  ⭐☆☆☆☆

Nginx работает, но вместо страницы отдаёт ошибку:

    curl http://localhost
    <html><head><title>403 Forbidden</title></head>...

Файл сайта на месте: `/var/www/html/index.html`.

**Цель:** `curl http://localhost` показывает страницу.
**Условие:** не открывай права на запись для всех (никаких `chmod 777`) —
на собеседовании за это сразу снимают баллы.

Когда закончишь — запусти `check`.
