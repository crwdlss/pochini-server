# Задача 04 — Порт занят  ⭐⭐☆☆☆

Новое приложение должно работать на порту 8080. Запускаешь — не стартует:

    start-app
    ❌ Приложение не запустилось, смотри /var/log/app.log

**Цель:** `start-app` запускает приложение, `curl http://localhost:8080`
отвечает `APP OK`.
**Условие:** порт приложения менять нельзя — на 8080 настроен балансировщик.

Когда закончишь — запусти `check`.
