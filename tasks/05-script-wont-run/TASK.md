# Задача 05 — Скрипт не запускается  ⭐⭐☆☆☆

Разработчик написал скрипт бэкапа на Windows и залил его на сервер.
Он должен запускаться напрямую, вот так:

    /opt/scripts/backup.sh

Но не запускается.

**Цель:** команда `/opt/scripts/backup.sh` выполняется и печатает «Бэкап выполнен».
**Условие:** запускать нужно именно так, без `bash backup.sh` и `sh backup.sh` —
скрипт будет вызываться из cron и CI.

Когда закончишь — запусти `check`.
