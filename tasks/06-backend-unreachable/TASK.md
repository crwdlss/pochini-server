# Задача 06 — Приложение не видит бэкенд  ⭐⭐⭐☆☆

Приложение обращается к бэкенду по имени `backend.local`.
Бэкенд запущен на этом же сервере и точно работает. Но:

    myapp-status
    ОШИБКА: backend недоступен по адресу http://backend.local:8000

**Цель:** `myapp-status` печатает `BACKEND OK`.
**Условие:** конфиг приложения `/etc/myapp/config.env` менять нельзя —
он общий для всех серверов.

Когда закончишь — запусти `check`.
