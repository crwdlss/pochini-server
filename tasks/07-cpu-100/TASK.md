# Задача 07 — Процессор загружен на 100%  ⭐⭐⭐☆☆

Мониторинг кричит: CPU 100%, сервер тормозит.
На сервере работает важное приложение `app-server` (порт 8081).

**Цель:** найти и остановить то, что грузит процессор, — так,
чтобы оно не вернулось.
**Условие:** `app-server` должен продолжать работать
(`curl http://localhost:8081` → `APP OK`).

Когда закончишь — запусти `check` (он понаблюдает за сервером 10 секунд).
