# Задача 08 — Cron молча не делает бэкап  ⭐⭐⭐⭐☆

Бэкап должен делаться каждую минуту по cron (`/etc/cron.d/backup`)
и записывать время в `/var/backups/last-backup.txt`.

Если запустить вручную, всё работает:

    backup-now
    backup ok

Но по расписанию файл не появляется. Ошибок нигде не видно.

**Цель:** бэкап сам выполняется по cron каждую минуту.

Когда закончишь — запусти `check` (он удалит файл и подождёт
до 70 секунд, пока cron создаст его заново).
