В Linux файл реально удаляется, только когда его закрыли ВСЕ процессы. Удалённый, но открытый файл продолжает занимать место.
Найди процессы, которые держат удалённые файлы: lsof | grep deleted  (или lsof +L1)
Посмотри файловые дескрипторы процесса: ls -l /proc/<pid>/fd/ — один из них указывает на "(deleted)".
Не убивая процесс, обнули файл через его дескриптор: : > /proc/<pid>/fd/<номер>  (или truncate -s 0 /proc/<pid>/fd/<номер>)
