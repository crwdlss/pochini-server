# Задача 10 — 502 Bad Gateway  ⭐⭐⭐⭐⭐

Классическая схема: nginx принимает запросы и проксирует их в API.
После вчерашнего деплоя сайт отдаёт:

    curl http://localhost
    <html><head><title>502 Bad Gateway</title></head>...

API запускается командой `start-api`, и она даже пишет, что всё запущено.

**Цель:** `curl http://localhost` (через nginx!) отвечает `API OK`.
Поломок здесь может быть больше одной.

Когда закончишь — запусти `check`.
